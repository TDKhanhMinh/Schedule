## 4. Phân tích Orphan Selectors (Dead CSS)

Qua rà soát mã nguồn các file `.tsx` và bundle sau build:
1. Rất nhiều class trong `legacy/app-dashboard-import.css` (`.import-matrix`, `.conflict-tree`, `.old-step-wizard`, v.v.) không còn xuất hiện trong bất kỳ file JSX nào do đã được tái cấu trúc thành component mới trong `features/`.
2. Trong `legacy/timetable-public.css`, các class layout cũ dành cho viewer tĩnh (`.public-grid-v1`, `.read-only-slot`) không còn được gọi.
3. Trong worktree hiện tại, các file legacy đã được ngắt import khỏi `styles.css`; các hook đang được sử dụng như feedback, bảng thời khóa biểu, lịch sử và public view đã có style semantic tương ứng trong các file mới. Những selector legacy không còn tham chiếu tiếp tục được loại bỏ theo từng feature, không khôi phục lại toàn bộ stylesheet cũ.
