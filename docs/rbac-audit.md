# RBAC và nhật ký kiểm toán — P1.2-T05

API hiện có ranh giới phân quyền theo phạm vi trường và nền tảng nhật ký chỉ
ghi thêm. Bộ điều hợp cục bộ cố ý tất định cho kiểm thử thí điểm/tích hợp; đây
không phải nhà cung cấp danh tính production.

## Danh tính request cục bộ

Business routes require these headers:

| Header         | Ý nghĩa                                                              |
| -------------- | -------------------------------------------------------------------- |
| `x-user-id`    | Stable actor identifier used in authorization and audit events       |
| `x-user-role`  | `ADMIN`, `SCHEDULER`, `REVIEWER`, or `VIEWER`                        |
| `x-school-id`  | Tenant/school scope; must match the route or request body scope      |
| `x-request-id` | Optional correlation ID; generated by request middleware when absent |

Thiếu header danh tính trả `401 AUTH_REQUIRED`. Vai trò không hợp lệ trả
`403 ROLE_INVALID`; a different school scope returns `403
SCHOOL_SCOPE_FORBIDDEN`; and an action outside the role matrix returns `403
PERMISSION_DENIED`.

## Ma trận quyền

| Role        | Read | Write master data | Import | Solve | Publish | Read audit |
| ----------- | ---: | ----------------: | -----: | ----: | ------: | ---------: |
| `ADMIN`     |  Yes |               Yes |    Yes |   Yes |     Yes |        Yes |
| `SCHEDULER` |  Yes |               Yes |    Yes |   Yes |      No |        Yes |
| `REVIEWER`  |  Yes |                No |     No |    No |     Yes |        Yes |
| `VIEWER`    |  Yes |                No |     No |    No |      No |        Yes |

Ánh xạ hiện tại được triển khai trong
`backend/src/auth/auth.constants.ts`. Route guards live in
`backend/src/auth/auth.guard.ts`; controllers must remain school-scoped when
they expose tenant data.

## Sự kiện nhật ký

Request thay đổi trạng thái thành công được ghi cho các hành động chuẩn hóa:
`CREATE`, `UPDATE`, `DELETE`, `IMPORT`, `SOLVE`, and `PUBLISH`.

Mỗi sự kiện ghi người thực hiện, vai trò, trường, thời điểm, hành động, loại thực thể,
entity identifier/key, and request correlation ID. Metadata is limited to
route/method or safe import summary fields; request bodies, uploaded files,
tokens, cookies, credentials and other secret-like values are redacted or not
copied.

Endpoint đọc là:

```text
GET /api/v1/schools/:schoolId/audit-logs?limit=50
```

Endpoint có cho cả bốn vai trò và luôn lọc theo phạm vi trường đã xác thực.
Migration `005_rbac_audit_foundation.sql` bỏ hành vi chống trùng cũ để hành động
lặp vẫn có thể kiểm toán.

## Ranh giới và cổng tiếp theo

Bộ điều hợp header cục bộ, schema database, guard API, interceptor nhật ký và
kiểm thử âm là bằng chứng triển khai cho P1.2-T05. Việc gắn các vai trò này
to the production identity provider, credential lifecycle, browser/E2E
evidence and stakeholder approval remain separate release gates. The Python
solver contract remains `schemaVersion: "1.0"` and is not changed by this
increment.
